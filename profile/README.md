# VKD

Open-source infrastructure, written in Rust. Small static binaries, auditable code, no per-node licensing.

| Project | What it is |
|---|---|
| [karen](https://github.com/vkdprojects/karen) | Hosting control plane: VPS, bare metal and web hosting |
| [pulse](https://github.com/vkdprojects/pulse) | Ultra-lightweight monitoring agent (gRPC/mTLS) |
| [vkdg](https://github.com/vkdprojects/vkdg) | AI gateway routing Claude/OpenAI-compatible clients |

All projects are MIT licensed. Contributions welcome — see each repo's `CONTRIBUTING.md`.
