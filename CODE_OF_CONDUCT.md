# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Harassment, personal attacks and discrimination are not tolerated.
Report incidents privately to the maintainers via GitHub (a private security advisory or direct message to an org owner).
Maintainers may remove, edit or reject contributions and ban participants who violate this code.
